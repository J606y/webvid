## Bug 1：网页全屏后播放器自定义样式全部失效 —— 已修（09-18）

**现象**（iPhone Safari 实测，非 webapp 也复现）：点全屏之后，手势层退化成裸文本堆在屏幕左上角
（`▶▶▶ 10 秒` / `2 倍速播放中`），控件的液态玻璃胶囊、细进度条等一并丢失。退出全屏就正常。

**根因**：`artplayer.mjs:2794` 在网页全屏时把 `.art-video-player` 搬到 `body`
（`FULLSCREEN_WEB_IN_BODY` 默认 true），`.player` 不再是它的祖先，`Play.vue` 里那 39 条
`:deep()` 编译出的 `.player[data-v-xxx] xxx` 整批失配。

**已做**：样式整体搬到全局 `frontend/src/assets/player.css`（覆盖掉原先那 144 行按不存在的
`.wv-player` 写的死代码），作用域 `.art-video-player.art-video-player`。`Play.vue` 的 scoped
块只剩页面容器，`:deep()` 归零。

**比交接文档多走的一步 —— 调 CSS 变量那条必须写三遍**：ArtPlayer 在
`.art-video-player.art-mobile`（(0,2,0)）里也在设 `--art-control-height: 38px`、
`--art-bottom-gap: 10px`，双写只有 (0,2,0)，打平就输给它（它的 `<style>` 排在产物 CSS 之后）。
迁移前那条是 (0,3,0)，三写把这一档原样补回。其余都是描述性选择器，前后特异性逐条相等。
验收里专门加了一条「竖屏控件行高压回 44px」盯着它，量到 38px 就是特异性又不够了。

## Bug 2：iPhone 上长按播放器进倍速时弹出放大镜 —— 已修，真机已验（09-19）

**现象**：长按进入 2 倍速的同时浮出那枚椭圆放大镜。倍速功能本身是好的。

**走过的三条错路**（都改完真机照旧，记下来别重走）：① `backdrop-filter` 采样错位；
② 播放器里的文字层没禁选（补 `-webkit-` 前缀）；③ iOS 往播放器外面找最近的可选文字
（于是整页禁选）。第 ③ 条是靠探针证伪的，已从 `Play.vue` 删掉。

**真因**：iOS 长按在播放器上放的是**折叠选区（光标）**，不是文字选区 —— 探针读到
`selectionchange 空选=true 选中="" @ <div.art-video-player …>`，而四处 `user-select`
全是 `none`。`user-select` 管的是能不能选中文字，管不住这个手势。逐个实测：拦 `selectstart`
无效、`html/body` 也禁选无效、选区一变就 `removeAllRanges` 无效，**只有在 `touchstart` 上
`preventDefault()` 能压住**。

**已做**（`playerGestures.js`）：`$video` 的 `touchstart` 改 `{ passive: false }` 并对单指
`preventDefault()`；代价是浏览器不再补发 `click`，于是在 `$video` 的 `touchend` 里按
「短按 < 400 ms 且没划开」自己派发一次 `MouseEvent('click')`，原有 click 链路不动。
细节见 `docs/PLAYER-GESTURES.md`。

**诊断工具留下了**：`frontend/select-probe.mjs` —— 局域网探针，手机直接打开，屏幕上实时显示
计算样式、selectionchange/touch 事件流，并带四种拦法的开关。这类「只在真机复现」的问题
以后一律先上它，别再靠猜。

## 真机走查带出的两条（09-19）

**设置面板在手机上被裁掉半截 —— 已修，真机已验。** ArtPlayer 给的高度上限是定值
（`.art-mobile` 180px），而 390 屏上播放器只有 ~206px 高，选项一多就顶出画面被 `overflow`
裁掉。改成 `min(300px, calc(100% - var(--art-control-height) - 10px))`，面板自带滚动。
验收加了两条断言（页面里塞 8 个占位选项，否则菜单太短验不出来）。

**竖屏进全屏、转横屏后 Safari 工具栏冒出来 —— 不是代码问题。** 网页全屏铺满的是网页视口，
浏览器外壳归 Safari 管，网页没有 API 能收起它；iPhone Safari 又不给任意元素用 Fullscreen API。
解法是把 WebVid 加到主屏幕以 standalone webapp 打开。**别再花时间查这条。**

顺带发现：`manifest.webmanifest` 写着 `"orientation": "portrait"`。iOS 忽略它，
但 Android 装成 PWA 会锁死竖屏 —— 对视频应用是错的，待用户定夺是否改成 `"any"`。

**移动端 dock 滑块按压放大（新增，09-19）。** 手指按在 dock 上时滑块涨到 1.06 并加深投影，
像被指尖提起来（iOS 分段控件的手感），拖动全程保持，松手落回。

要点：**涨缩用独立的 `scale` 属性，不并进 `transform`**。拖动期间 transform 必须瞬时跟手，
原来是整条 `transition: none` —— 那会把涨缩一起掐掉，变成硬邦邦地瞬间弹大。现在拖动时的
inline transition 换成「只留 `scale` + `box-shadow`」，transform 不在列表里即为瞬时。
涨的那 6% 落在 `.tabbar` 的 5px 内边距里，实测四边都还在 dock 内，不会溢出圆角。
只动 scale/box-shadow，无 filter 参与（#35 教训）。

验收：`frontend/dock-press-check.mjs`（新增，11 项全过）。它还守着「拖动时 transform 不参与
缓动」这一条 —— 那是本次最容易写坏、又最难靠眼睛发现的地方（手感会变成「拖不动」）。

**iOS 长按 dock 会弹 Safari 链接预览（新增，09-19 修）。** 导航项都是 `router-link`（`<a>`），
iOS 长按链接会浮出预览卡片，盖住 dock 还打断滑块拖动。修法是在 `.topbar` / `.tabbar` 上设
`-webkit-touch-callout: none` + 禁选（两个属性都可继承，容器上一次盖住所有项）；顶栏的
brand 也是链接，同一条规则一并覆盖。Chromium 不认 `-webkit-touch-callout`，验收里那条断言
会打出提示 —— **浮层还弹不弹只有 iPhone 说了算**。

## 环境要点（容易栽的）

- **改前端必须 `go build` 重嵌**：前端由 `public/public.go` 的 `//go:embed all:dist` 编译进二进制，
  只跑 `vite build` 不重新编译的话，跑着的进程用的还是旧前端。为此白查过好几轮。
- **`npx vite build` 会 segfault**（V8 fatal error，连续两次复现），改用 `npm run build` 正常。
- **某些注释会让前端构建必崩（09-19 实测）**：`npm run build` 段错误
  （`Check failed: maybe_code.has_value()`），或 rollup 报
  `Cannot define property Symbol(Entities), object is not extensible`。
  别怀疑代码、别删缓存 —— 查过了：NODE_OPTIONS 为空、内存充足、rollup 原生包完好、
  清 `node-compile-cache` 无效。真凶是 `App.vue` 样式块里一段**四行中文注释**：摘掉必过、
  原样贴回必崩，A/B 各两次。同文件另外几十条中文注释都正常，注释里也没有 `*/` 之类的构造，
  更像是 SFC 样式块长度撞上了某个原生路径的边界（vite 6.4.3 / rollup 4 / node 24.15）。
  **应对：把长注释拆短，或把缘由写进文档、代码里只留一两行。** 触发那段原文：

  ```
  /* 导航栏里全是 router-link，iOS 长按链接会弹 Safari 的链接预览浮层（那一层浮出来，
     底下的 dock 拖动就断了）。-webkit-touch-callout 正是管它的，两个属性都可继承，
     设在容器上一次盖住所有项；user-select 一并关掉，免得长按改成选中「视频库」那几个字。
     桌面端一并生效：那里长按同样没有意义。 */
  ```
